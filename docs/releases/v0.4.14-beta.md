## Beacon v0.4.14-beta

Keeps the public “Service suspended” page up when a project is off but Beacon
is still running — including across Beacon restarts.

### Suspended projects

- Suspension is saved on the project, so turning a site off survives a Beacon
  restart instead of leaving the hostname empty.
- On startup, Beacon re-binds the fallback page for every suspended website or
  API that has a port.
- API projects get the same suspended page as websites.

### Install

In the app: **Updates → Beacon** → install **v0.4.14-beta**.

Or on the server:

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /home/vadmin/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.4.14-beta
sudo systemctl restart systemdash
```
