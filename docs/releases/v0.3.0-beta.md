## Beacon v0.3.0-beta

Still a **beta** (not a 1.0). This is a minor bump because the product name and a
few major surfaces changed, not because anything is final.

The UI, docs, and GitHub release now say **Beacon**. Install paths, the
`systemdash` systemd unit, tarball names, and `SYSTEMDASH_*` environment
variables stay the same so upgrades keep working.

### Beacon

- User-facing name, page title, favicon, and login/setup copy.
- Lime palette alongside the existing classic theme (header toggle).
- Live connection meter in the sidebar; the favicon tints with connection state.

### Files

- **Network shares** — add, reconnect, and remove SMB/CIFS (and similar) mounts;
  they persist across restarts.
- **Trash** — delete moves items to a recoverable trash (30-day retention), with
  restore / empty from Files.
- **Disk map** — WizTree-style usage treemap for a folder or volume.

### Backups

- Snapshots of Beacon data (accounts, settings, projects, history, shares).
- Manual create/download/restore from **Updates**, plus an automatic snapshot
  before an in-app update.

### Activity

- Retention and size caps (days / MB), on/off, and clearer stats instead of a
  hard row limit.

### Projects

- Service kinds: website / API / worker, optional embed preview, health path,
  notes.
- Colorized action logs (ANSI + status tones).

### Upgrade from v0.2.2-beta

In the app: **Updates → Beacon** → install **v0.3.0-beta**.

Or on the server:

```bash
export SYSTEMDASH_HOME=/opt/systemdash
bash /opt/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.3.0-beta
sudo systemctl restart systemdash
```
