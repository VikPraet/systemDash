## Beacon v0.4.13-beta

Applies the friendlier Files drive names to the Overview Storage panel.

### Overview

- The Storage panel uses the same labels as Files This PC: Docker container
  names, short fallbacks for overlay layers, and local nicknames.
- Kernel and other junk mounts (efivarfs, `/sys`, snap loops, and similar) are
  hidden here too, matching the Files drive list.

### Install

In the app: **Updates → Beacon** → install **v0.4.13-beta**.

Or on the server:

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /home/vadmin/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.4.13-beta
sudo systemctl restart systemdash
```
