## Beacon v0.4.5-beta

**Experimental** patch on **v0.4.4-beta**. Live system telemetry (Overview gauges
and the sidebar live/disconnected meter) now uses Server-Sent Events instead of
polling `/api/system` once a second.

`GET /api/system` is still there for one-shot reads and debugging.

This is a behaviour change on the hot path. If Overview stalls, reconnects
loop, or a signed-out session still shows live stats, roll back to **v0.4.4-beta**.

### What to check

- Overview CPU / memory / disks / GPUs still update about once a second.
- Disconnect the host or stop the service: reconnect overlay and favicon should
  still flip, then recover on their own.
- Sign out or revoke the session: the stream should drop and the UI should
  return to login.

### Upgrade from v0.4.4-beta

In the app: **Updates → Beacon** → install **v0.4.5-beta**.

Or on the server:

```bash
export SYSTEMDASH_HOME=/opt/systemdash
bash /opt/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.4.5-beta
sudo systemctl restart systemdash
```
