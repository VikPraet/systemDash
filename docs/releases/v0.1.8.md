## SystemDash v0.1.8

Mobile-friendly UI and **host power control** for admins (restart, shut down, force power off).

### Mobile support

The dashboard is usable on phones and narrow browser windows (breakpoint **720px**).

**Navigation**
- Hamburger menu with slide-out drawer (replaces the broken horizontal nav bar)
- Compact top bar with live-status dot and logout
- Drawer closes on route change or backdrop tap; body scroll locks while open

**Layout**
- Overview grid and stat cards stack on small screens
- History time-range picker uses a 4-column button grid instead of one overflowing row
- Chart card headers and legends wrap cleanly

**Data tables & panels**
- Processes, Files, Containers, and package updates tables scroll horizontally when needed
- **Activity** active sessions render as labeled cards (revoke always visible top-right)
- **Users** list uses per-user cards with actions pinned beside the name
- **Updates** toolbar stacks on mobile: search + summary on top, action buttons in a 2-column grid

**Other**
- Terminal height uses `dvh`; split panes stack vertically on mobile
- Modals respect safe-area insets on notched devices
- Shared breakpoint constant in `web/src/theme/media.ts`

### Host power control (admin)

New **Power** section on the Overview → System card (admins only).

| Action | Description |
|--------|-------------|
| **Restart** | Reboots the host |
| **Shut down** | Graceful shutdown |
| **Force power off** | Immediate power cut (unsaved work may be lost) |

- Confirmation modal — type `REBOOT`, `SHUTDOWN`, or `POWEROFF` to proceed
- **5 second delay** before the OS command runs (API responds and audit log writes first)
- Audited in Activity as `system.reboot`, `system.shutdown`, `system.poweroff`
- **Windows:** `shutdown /r` or `/s` (force flag for power off)
- **Linux:** `systemctl reboot` / `poweroff` / `poweroff --force`
- **macOS:** `shutdown -r` / `-h` / `-h -u`

**API**
- `GET /api/power/capabilities`
- `POST /api/power/run` — `{ "action": "reboot"|"shutdown"|"poweroff", "confirm": "REBOOT"|…, "delaySeconds": 5 }`

**Linux sudo** (when not running as root):

```text
systemdash ALL=(root) NOPASSWD: /usr/bin/systemctl reboot, /usr/bin/systemctl poweroff
```

**Disable power ops:** set `SYSTEMDASH_DISABLE_POWER_OPS=1` on the server.

### Upgrade

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /home/vadmin/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.1.8
sudo systemctl restart systemdash
```

Or use **Updates → SystemDash app update** in the UI if a newer release is reported.
