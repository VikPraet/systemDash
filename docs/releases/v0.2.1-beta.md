## SystemDash v0.2.1-beta

Still a **beta** (not a 1.0). The extra `.1` / `.2` after `beta` were just “which draft of 0.2.0”, not hotfixes. From here, a new try is a normal patch with `-beta` on the end: `0.2.1-beta`, then `0.2.2-beta`, and so on.

### Public access (this dashboard)

- **Overview → Public access** exposes *this* SystemDash on the existing cloudflared tunnel (`127.0.0.1:3001`). It does not clone a second copy via Projects.
- Same tunnel as your other sites. Type a hostname, confirm, and Save writes the ingress rule.

### Projects / cloudflared

- Site URL can still be picked from hostnames already in the local config.
- **New** hostnames (with a port) are added to that config; existing ones can be retargeted to a new port.
- **Cloudflare DNS** box shows the CNAME to paste if auto-DNS did not run: `hostname → {tunnel-id}.cfargotunnel.com` (Proxied). Copy buttons included.
- Optional Cloudflare API token is only for **visit counts** (Zone Analytics), not for the tunnel.

### Sites

- Live health on project cards (public URL, origin port, runtime).
- 24h visits/requests when a Cloudflare analytics token is connected.

### Upgrade from v0.2.0-beta.2

In the app: **Updates → SystemDash** → install **v0.2.1-beta**.

Or on the server:

```bash
export SYSTEMDASH_HOME=/opt/systemdash
bash /opt/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.2.1-beta
sudo systemctl restart systemdash
```
