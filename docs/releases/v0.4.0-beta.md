## Beacon v0.4.0-beta

Still a **beta** (not a 1.0). Minor bump because the dashboard and theme system
are new major surfaces, not a polish pass on v0.3.0-beta.

### Dashboard

- **Custom layouts** on Overview, History, Files, and Projects — drag, resize,
  add, hide, group, and reset panels.
- Per-panel **role visibility** (viewer / user / admin).
- One admin at a time can edit; the lock expires after idle so someone else can
  take over.

### Themes

- Five built-in themes, each with dark and light: **Classic**, **Lime**,
  **Phosphor**, **Ember**, **Midnight**.
- Theme picker in the header. Admins can duplicate, create, import, and export
  themes; custom themes persist on the host.
- Live preview in the theme editor (colors, gauges, bars, atmosphere).

### Also in this build

- Reconnect overlay when the host drops off, instead of a silent blank page.
- Skeleton placeholders while overview / charts / public-access / power widgets
  load.
- Project cards can show a live embed preview for website services.

### Upgrade from v0.3.0-beta

In the app: **Updates → Beacon** → install **v0.4.0-beta**.

Or on the server:

```bash
export SYSTEMDASH_HOME=/opt/systemdash
bash /opt/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.4.0-beta
sudo systemctl restart systemdash
```
