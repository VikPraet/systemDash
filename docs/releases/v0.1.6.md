## SystemDash v0.1.6

Ships setup scripts inside the release tarball so they exist after `install-release.sh`.

### Fixes

- **`scripts/` in release tarball** — `configure-service-user.sh`, `systemdash-vadmin.service.example`, `install-release.sh`
- **`configure-service-user.sh`** — `chown` install tree to the service user when switching off root
- **`install-release.sh`** — prints correct post-install paths under `current/scripts/`

### Finish v0.1.5 setup (without reinstalling)

If you already installed v0.1.5 but scripts were missing:

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
mkdir -p /home/vadmin/systemdash/current/scripts
curl -fsSL -o /home/vadmin/systemdash/current/scripts/configure-service-user.sh \
  https://raw.githubusercontent.com/VikPraet/systemDash/v0.1.6/scripts/configure-service-user.sh
curl -fsSL -o /home/vadmin/systemdash/current/scripts/systemdash-vadmin.service.example \
  https://raw.githubusercontent.com/VikPraet/systemDash/v0.1.6/scripts/systemdash-vadmin.service.example
chmod +x /home/vadmin/systemdash/current/scripts/configure-service-user.sh
bash /home/vadmin/systemdash/current/scripts/configure-service-user.sh vadmin
sudo cp /home/vadmin/systemdash/current/scripts/systemdash-vadmin.service.example /etc/systemd/system/systemdash.service
sudo systemctl daemon-reload && sudo systemctl restart systemdash
```

### Upgrade from v0.1.5

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /home/vadmin/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.1.6
cd /home/vadmin/systemdash/current && bash scripts/configure-service-user.sh vadmin
sudo cp scripts/systemdash-vadmin.service.example /etc/systemd/system/systemdash.service
sudo systemctl daemon-reload && sudo systemctl restart systemdash
```
