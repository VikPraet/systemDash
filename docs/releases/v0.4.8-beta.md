## Beacon v0.4.8-beta

**Experimental** patch on **v0.4.7-beta**. Stop a bad project or tunnel from
taking Beacon down, and stop systemd from crash-looping a unit that was never
built.

### Resilience

- Unexpected exceptions and rejected promises are logged; the dashboard process
  stays up. Request failures become HTTP 500 instead of a dead Node process.
- Live stats: send a stream ping and prime a snapshot at boot so Cloudflare does
  not hold an empty pipe. If `/api/health` still answers, the UI shows a banner
  instead of “the host isn’t responding.”

### Projects / systemd

- Refuse to enable a systemd unit when the working directory or start file does
  not exist (the `/opt/hook` miss).
- `EnvironmentFile=-…` so a missing env file cannot make systemd fail spawn.
- If the unit does not stay active, Beacon disables it so it cannot restart
  every few seconds.
- Unlink or delete a systemd project runs `disable --now`; purge also removes
  the system unit file.
- New git clones default under `/home/vadmin` (or the saved clone folder), not
  `/opt`.

### Cloudflare

- Refuse to write `config.yml` if the patch would drop an existing hostname
  such as `dash.ill4.life`.

### Upgrade from v0.4.7-beta

In the app: **Updates → Beacon** → install **v0.4.8-beta**.

Or on the server:

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /home/vadmin/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.4.8-beta
sudo systemctl restart systemdash
```
