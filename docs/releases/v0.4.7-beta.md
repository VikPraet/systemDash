## Beacon v0.4.7-beta

**Experimental** patch on **v0.4.6-beta**. In-app file preview: images, video,
audio, and PDFs open in the editor instead of as text. Binary files get a
download card. The Edit action is hidden for non-text files.

Adds `GET /api/fs/preview` so range requests (video) are not logged as
downloads.

### Upgrade from v0.4.6-beta

In the app: **Updates → Beacon** → install **v0.4.7-beta**.

Or on the server:

```bash
export SYSTEMDASH_HOME=/opt/systemdash
bash /opt/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.4.7-beta
sudo systemctl restart systemdash
```
