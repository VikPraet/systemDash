## SystemDash v0.1.7

Fixes **502 errors**, slow Updates tab, and spurious terminal disconnects when switching pages.

### Fixes

- **No `apt-get update` on tab open** — only runs when you click **Refresh**
- **Fast package list** — `apt list --upgradable` only; optional **Load descriptions**
- **No slow `winget` scan on tab open** — Windows/macOS scans only on **Refresh** (fixes slow `yarn dev`)
- **Per-request dedupe bug** — fast and slow update checks no longer block each other
- **45s status cache** — repeat visits to Updates are instant
- **Terminal** — no reconnect spam while hidden; reconnects when you return to the Terminal tab
- **Sidebar version** — shows installed version only; GitHub check stays on the Updates page
- **dev:remote** — longer Vite proxy timeout for slow apt operations

### Sudo on NUC

Passwordless sudo is set by `configure-service-user.sh` (your run showed `apt-get: OK`). Verify:

```bash
sudo -u vadmin sudo -n apt-get -qq update
cat /etc/sudoers.d/systemdash-vadmin
```

### Upgrade

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /home/vadmin/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.1.7
sudo systemctl restart systemdash
```
