## Beacon v0.4.10-beta

### Package updates

- Hide Ubuntu phased packages from the pending list. Apt lists them as
  upgradable, then skips them until the rollout includes this machine.
- Show a short note with an **Install anyway** action when updates are waiting
  on phasing.

### Suspended websites

- When a website project is turned off, Beacon serves a temporary “Service
  suspended” page on its port instead of leaving the hostname empty.
- Turning the project back on releases that port before starting the real
  service.

### Projects

- Edit a project’s git remote and branch in project details. Saving updates
  `origin` in the checkout so pull/fetch use the new URL.
- Worker remotes are optional. Changing the remote picks a matching git
  account when one is configured.
- Block deployment actions while a project is suspended.

### Install

In the app: **Updates → Beacon** → install **v0.4.10-beta**.

Or on the server:

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /home/vadmin/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.4.10-beta
sudo systemctl restart systemdash
```
