## SystemDash v0.2.0-beta.1

**Pre-release** for testing Projects and site deploys on a real host. Not a stable Latest release.

### Projects

Manage other git repos on this machine (clone/attach, GitHub/GitLab token, pull and structured actions).

- **Site profile** per project: public URL, how it runs (Docker / Compose / systemd / static files), port, start on boot
- Default **Pull** + ensure/publish action when a run kind is set
- Compose file and publish-from paths are relative to the project folder; publish-to is an absolute path on the host (with Browse)
- **Site URL** can be picked from a local **cloudflared** `config.yml` ingress list (read-only — does not add DNS or tunnel routes)

### Upgrade (this is a beta)

GitHub will not treat this as Latest. On the NUC, install **this tag** once:

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /home/vadmin/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.2.0-beta.1
sudo systemctl restart systemdash
```

After this build is running, **Updates → SystemDash** can offer later betas. `install-release.sh … latest` still tracks the last stable release only.
