## Beacon v0.4.12-beta

Clearer drive names on the Files This PC view, especially for Docker mounts.

### Files

- Docker overlay mounts show the running container name instead of a long
  `overlay2` hash path. If Docker is unreachable, they fall back to a short
  `Docker · …` label.
- Kernel and other junk mounts (efivarfs, `/sys`, snap loops, and similar) are
  hidden from the drive list.
- Rename any drive card with the pencil control. Nicknames are saved locally in
  settings and do not rename anything on disk. Clear the field to restore the
  automatic label.
- Breadcrumbs use the friendly drive name when you open one of these mounts.

### Install

In the app: **Updates → Beacon** → install **v0.4.12-beta**.

Or on the server:

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /home/vadmin/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.4.12-beta
sudo systemctl restart systemdash
```
