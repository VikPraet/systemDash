## Beacon v0.4.4-beta

Small experiment on **v0.4.3**. Docker workers can run without a Dockerfile: a
plain image mounts the project folder at `/app`. Published images still need no
files on the host. Worker containers show on the Containers page with a link
back to the project.

### Upgrade from v0.4.3

In the app: **Updates → Beacon** → install **v0.4.4-beta**.

Or on the server:

```bash
export SYSTEMDASH_HOME=/opt/systemdash
bash /opt/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.4.4-beta
sudo systemctl restart systemdash
```
