## Beacon v0.4.9-beta

### Project controls and startup settings

- Turn on or suspend projects from cards and project details. Controls reflect the reported runtime state.
- Keep card controls in a footer outside the scrollable content. Give project details priority over previews.
- Read configured systemd and Docker startup settings when loading projects, including terminal changes, and apply changes made in Beacon to the runtime.
- Respect the startup preference when applying systemd services and Docker containers.
- Read named systemd status properties reliably.

Suspending stops the runtime for the current session; it leaves the startup preference unchanged. Projects must have the correct runtime and service/container configured. Install this backend update to use the new controls with a remote development UI.

### Install

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /home/vadmin/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.4.9-beta
sudo systemctl restart systemdash
```

### Validation

Server and web production builds and 64 automated tests passed on Windows. Live Linux service controls require host verification.
