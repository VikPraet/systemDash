## Beacon v0.4.11-beta

A Network page for live traffic, plus history that records how much data the
host actually moved.

### Network

- New **Network** page in the sidebar. Remote sockets are drawn on a world map
  at the peer’s city. Click a destination, or this host, to open the matching
  connections.
- The map overlay shows live receive/send on physical adapters and the process
  with the most remote sockets.
- The connection list shows process, inferred service (HTTPS, SSH, and other
  well-known ports), direction (in / out), reverse DNS, and traffic. Open a row
  for local and peer addresses, ports, and byte totals.
- Per-socket byte counters depend on the OS. On Windows, Beacon needs to be
  running elevated. On Linux they come from `ss`. Service and direction are
  inferred from ports either way.
- Public peer locations use the same cached ip-api lookup as the activity log.
  Private and local addresses stay on-host and are not sent out.

### Usage over time

- The history recorder now stores byte deltas for physical adapters, not only
  the instantaneous rate. Existing databases gain the new columns on startup.
- **Network** includes a usage timeline for 24 hours (hourly), 7 days, or 30
  days (daily). Switch the unit between Auto, KB, MB, and GB.
- **History** and the dashboard chart catalog include a **Data transferred**
  panel for the same totals. Hourly bars are used for ranges up to 48 hours;
  longer ranges use daily bars.
- Bars stay empty until the recorder has sampled after this upgrade. Rates on
  the existing Network history chart are unchanged.

### Disk history

- Disk charts split read and write per physical disk, with a live rate on each
  row. The Live range follows the system stream the same way CPU and memory do.

### Install

In the app: **Updates → Beacon** → install **v0.4.11-beta**.

Or on the server:

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /home/vadmin/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.4.11-beta
sudo systemctl restart systemdash
```
