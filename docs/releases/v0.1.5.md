## SystemDash v0.1.5

Fixes and tooling to run as a normal user (`vadmin`) instead of root.

### Fixes

- **Sidebar version** — reads `VERSION.json` / `package.json` instead of showing stale `v0.1.0`
- **Version badge size** — compact 11px styling restored for the clickable update badge
- **In-app upgrade as non-root** — uses `sudo systemctl restart systemdash` when not running as root

### New scripts

- **`scripts/configure-service-user.sh`** — docker group + passwordless sudo for `apt` and `systemctl restart systemdash`
- **`scripts/systemdash-vadmin.service.example`** — systemd unit for home NUC (`User=vadmin`, `SYSTEMDASH_HOME`, `SYSTEMDASH_DATA_DIR`)

### Upgrade

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /path/to/install-release.sh VikPraet/systemDash v0.1.5
bash scripts/configure-service-user.sh vadmin
sudo cp scripts/systemdash-vadmin.service.example /etc/systemd/system/systemdash.service
sudo systemctl daemon-reload && sudo systemctl restart systemdash
```

After this release the sidebar should show **v0.1.5** and the terminal should use **vadmin** (once the example unit is applied).
