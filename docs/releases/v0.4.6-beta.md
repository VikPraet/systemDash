## Beacon v0.4.6-beta

**Experimental** patch on **v0.4.5-beta**. Two follow-ups to the SSE telemetry
change.

### Live charts

The History **Live** range now draws ~1s samples from the system stream. The
save interval is still only how often metrics are written to disk. Longer
ranges (15m, 1h, …) are unchanged.

Process-count charts still follow the recorder; that metric is not in the
system snapshot.

### Favicon

The tab icon no longer rebuilds on every telemetry tick. It updates when the
connection state actually changes (live / disconnected / connecting).

### Upgrade from v0.4.5-beta

In the app: **Updates → Beacon** → install **v0.4.6-beta**.

Or on the server:

```bash
export SYSTEMDASH_HOME=/opt/systemdash
bash /opt/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.4.6-beta
sudo systemctl restart systemdash
```
