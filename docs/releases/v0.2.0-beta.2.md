## SystemDash v0.2.0-beta.2

Still a **pre-release**. GitHub Releases stay prerelease until a real 1.0.

### Updates

- **Updates → SystemDash** lists every build (including betas). Pick a version and Install
- `install-release.sh latest` uses the newest GitHub release when there is no stable Latest

### Projects

- Git no longer fails with “dubious ownership” on folders owned by another user
- New Site URLs can be **added to the local cloudflared config** (needs a port; reloads the tunnel; DNS is best-effort)
- Action step-type dropdown opens upward when needed and scrolls
- Command steps use a single-line field instead of a tall textarea

### Upgrade from v0.2.0-beta.1

The in-app picker is in **this** build, so install the tag once:

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /home/vadmin/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.2.0-beta.2
sudo systemctl restart systemdash
```

After that, later betas can be chosen under **Updates → SystemDash**.
