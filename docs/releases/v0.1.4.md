## SystemDash v0.1.4

Webmin-style **OS package updates** and **one-click SystemDash upgrades** from GitHub Releases.

### Highlights

- **Updates page** (`/updates`) — package table with search, checkboxes, refresh, progress bar, and live install logs
- **Overview teasers** — quick links to package updates and SystemDash app updates
- **Sidebar version badge** — shows when a newer GitHub release is available (admin)
- **In-app self-update** — download release tarball, extract, flip `current` symlink, restart via systemd (Linux release installs)
- **GitHub release check** — defaults to `VikPraet/systemDash`; no token required for public repos

### Server configuration (optional)

```ini
Environment=SYSTEMDASH_HOME=/home/vadmin/systemdash
Environment=GITHUB_REPO=VikPraet/systemDash
```

`GITHUB_TOKEN` is only needed for private repositories or higher GitHub API rate limits.

### Upgrade from v0.1.2 / v0.1.3

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /path/to/install-release.sh VikPraet/systemDash v0.1.4
sudo systemctl restart systemdash
```

After v0.1.4 is installed, future upgrades can be done from **Updates → SystemDash** in the UI.
