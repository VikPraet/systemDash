## Beacon v0.4.1-beta

Patch on **v0.4.0-beta**. Dropdowns in dialogs (Add project, folder picker, and
the rest) were opening behind the overlay, so the list never showed.

### Upgrade from v0.4.0-beta

In the app: **Updates → Beacon** → install **v0.4.1-beta**.

Or on the server:

```bash
export SYSTEMDASH_HOME=/opt/systemdash
bash /opt/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.4.1-beta
sudo systemctl restart systemdash
```
