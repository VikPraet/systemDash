## SystemDash v0.1.9

New **login screen** (no stock background image), **username/password recovery**, and an optional **host shell user** for the in-app terminal.

### Login & recovery

- Login/setup use a CSS telemetry layout instead of `login-bg.png`
- **Forgot username or password?** on the sign-in screen
  - Username: pick your recovery question and answer
  - Password: username + answer → set a new password
- First-run setup requires a recovery question
- Existing accounts: banner after sign-in, or the key icon next to your name
- Recovery answers are hashed; failed attempts are rate-limited

### Terminal OS user

Optional Linux username in **Terminal → settings** (stored on this machine only).

- Empty: terminal runs as the systemd service user
- Set, and the service is still root: new tabs `su -` into that account’s home
- **Files → Home** follows the same account
- Also configurable with `SYSTEMDASH_OS_USER` (see the vadmin service example)

### Upgrade

```bash
export SYSTEMDASH_HOME=/home/vadmin/systemdash
bash /home/vadmin/systemdash/current/scripts/install-release.sh VikPraet/systemDash v0.1.9
sudo systemctl restart systemdash
```

Or use **Updates → SystemDash app update** in the UI if a newer release is reported.

After upgrading, sign in once and set a recovery question so you can get back in if you forget your username or password.
