## SystemDash v0.2.2-beta

Patch on **v0.2.1-beta**. No new features.

### Public access

Once a hostname is on the tunnel, Overview shows a small **Online** row with the public link. Setup, DNS copy, and the hostname list stay hidden until you click **Change**.

### Upgrade from v0.2.1-beta

In the app: **Updates → SystemDash** → install **v0.2.2-beta**.
